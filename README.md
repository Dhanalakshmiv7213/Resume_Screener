# AI Resume Screener

An AI-powered resume screening application built using FastAPI, NLP, and Sentence Transformers.

## Features
- Upload resume PDFs
- Extract skills automatically
- Compare resumes with job descriptions
- NLP semantic similarity scoring
- SQLite database integration

## Tech Stack
- FastAPI
- Python
- Sentence Transformers
- SQLite
- HTML/CSS/JavaScript

## Run Backend

uvicorn main:app --reload
